# Nitto Kohki × An Phát — Delvo C-Series

Landing page HTML/CSS/JavaScript đã chốt, gồm ảnh và font cục bộ.

- Website GitHub Pages: https://lebad280324.github.io/notto-kohki-an-phat/
- Chạy local: `npm start` rồi mở http://localhost:3001
- Kiểm tra: `npm run check` (Node.js và Python 3, không cần cài thư viện)
- Xuất bản: vào Actions → Deploy landing page to GitHub Pages → Run workflow. Workflow chỉ chạy thủ công.

Form liên hệ hiện chuẩn bị email gửi tới contact@anphatco.vn để khách tự gửi qua ứng dụng email; chưa kết nối MISA aiMarketing.

Ảnh và nguồn tài nguyên: xem CREDITS.md. Giấy phép font trong assets/fonts/.
